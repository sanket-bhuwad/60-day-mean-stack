# 60-Day MEAN Stack Roadmap

Each day has one primary outcome. The order follows the dependency chain from
web fundamentals to a complete full-stack application.

## Phase 1: Foundations (Days 1-4)

1. Semantic personal profile page
2. Accessible registration form
3. CSS selectors and box model
4. Responsive layout with Grid and Flexbox

## Phase 2: JavaScript (Days 5-14)

5. Variables, data types, and operators
6. Conditions and a grading calculator
7. Loops, sums, factorials, and number patterns
8. Functions and reusable helpers
9. Arrays and array transformations
10. Objects and destructuring
11. String and number problem solving
12. DOM selection and events
13. Form validation and browser storage
14. Mini project: task tracker

## Phase 3: MongoDB (Days 15-21)

15. NoSQL concepts and document design
16. CRUD operations
17. Query operators and projections
18. Indexes and query performance
19. Schema validation
20. Aggregation pipelines
21. Data modelling for a task platform

## Phase 4: Express (Days 22-28)

22. Express application setup
23. Routing and controllers
24. Middleware and request lifecycle
25. Input validation
26. Centralised error handling
27. MongoDB integration
28. REST API for the task platform

## Phase 5: Angular (Days 29-42)

29. Angular workspace and components
30. Templates and data binding
31. Directives and pipes
32. Services and dependency injection
33. Routing and navigation
34. Reactive forms
35. HTTP client and API integration
36. Loading and error states
37. Authentication UI
38. Route guards
39. Shared components
40. RxJS fundamentals
41. Feature-based folder structure
42. Angular task platform client

## Phase 6: Node.js engineering (Days 43-49)

43. Node.js runtime and modules
44. npm scripts and configuration
45. Async patterns and streams
46. Logging and observability
47. Unit and integration testing
48. Security and production configuration
49. API documentation and health checks

## Phase 7: Portfolio projects (Days 50-60)

50. Project planning and acceptance criteria
51. Task platform backend foundation
52. Task platform authentication
53. Task platform core workflows
54. Task platform Angular dashboard
55. Task platform tests and accessibility
56. Project deployment preparation
57. Project two: requirements and data model
58. Project two: API and Angular implementation
59. Project two: testing, performance, and polish
60. Portfolio review, documentation, and demo

## Daily completion checklist

- [ ] Define the day's outcome before coding.
- [ ] Implement the smallest complete example.
- [ ] Add a README with run instructions and learning notes.
- [ ] Run the relevant formatter, tests, or manual verification.
- [ ] Commit one coherent change with a descriptive message.
