# Day 12: Array methods

## Objective

Practise `map`, `filter`, `reduce`, `find`, `some`, and `every` with arrays of
values and objects.

## Practice

- Transform values with `map`.
- Select matching values with `filter`.
- Calculate a total with `reduce`.
- Find the first matching item with `find`.
- Check whether at least one item matches with `some`.
- Check whether every item matches with `every`.

## How to run

```powershell
node .\02-javascript\day-12-array-methods\main.js
```

## What I learned

- `map` returns one transformed value for each input item.
- `filter` returns every item that passes its condition.
- `reduce` combines an array into one result.
- `find` returns the first matching item or `undefined`.
- `some` returns `true` when at least one item passes its condition.
- `every` returns `true` only when all items pass their condition.

## Verification

The script prints the result of each array method when run with Node.js.
