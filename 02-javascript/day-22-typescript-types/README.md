# Day 22: TypeScript types

## Objective

Practise unions, narrowing, optional properties, and generics.

## Practice

- Narrow a `string | number` value safely.
- Handle an optional note with a default.
- Use a generic `Box<T>` to keep values type-safe.

## How to run

Compile with `tsc main.ts --strict --target ES2020` and run the generated
`main.js` with Node.js.
