# Day 18: Closures and scope

## Objective

Practise lexical scope, closures, hoisting, and `this` in JavaScript.

## Practice

- Compare block, function, and global scope.
- Use a closure to create private state.
- Observe declaration hoisting and temporal dead zones.
- Preserve `this` with an arrow function and `bind`.

## How to run

Run `node main.js` from this folder.

## Verification

The script prints examples for each topic and demonstrates a private counter
that can only be changed through its returned methods.
