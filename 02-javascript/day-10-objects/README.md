# Day 10: Objects and destructuring

This day is planned in [the 60-day roadmap](../../docs/roadmap.md).

## Objective

Practise creating and updating objects, extracting values with destructuring,
and transforming arrays of objects.

## Practice

- Create an object and read, update, and add its properties.
- Destructure object properties, renamed properties, default values, and nested
  objects.
- Use `map`, `filter`, `find`, and `reduce` with an array of objects.

## How to run

```powershell
node .\02-javascript\day-10-objects\main.js
```

## What I learned

- Objects group related values using named properties.
- Destructuring assigns object properties to local variables concisely.
- Array methods can destructure each object while selecting or transforming
  data.

## Verification

The script prints object property updates, destructured values, lesson
selections, and a total calculated from an array of objects.
