# Day 19: Problem-solving

## Objective

Solve beginner problems using strings, arrays, and objects.

## Practice

`main.js` contains ten small, reusable functions:

1. Reverse a string
2. Count vowels
3. Check for a palindrome
4. Find the largest number
5. Remove duplicate values
6. Sum an array
7. Capitalize every word
8. Group words by their first letter
9. Count item frequencies
10. Find the first repeated value

## How to run

Run `node main.js` from this folder. The sample calls print their results.
