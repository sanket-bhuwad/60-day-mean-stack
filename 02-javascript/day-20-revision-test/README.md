# Day 20: Revision test

## Objective

Rebuild a searchable task tracker without following a tutorial.

## Features

- Add tasks with a title and category.
- Search tasks by title or category.
- Filter by all, active, or completed tasks.
- Toggle completion and delete tasks.
- Persist tasks in `localStorage`.

## How to run

Open `index.html` in a browser. No build tools or dependencies are required.
